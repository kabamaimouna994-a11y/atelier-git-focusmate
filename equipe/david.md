## Quiz

1. Juste après `git commit`, où se trouve mon commit ?
   Seulement dans mon dépôt local (ici, dans le Codespace). Il n'est pas encore sur GitHub.

2. Juste après `git push`, où se trouve-t-il ?
   Dans mon dépôt local et sur le dépôt distant GitHub (origin), où les autres peuvent le récupérer.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?
   Le commit est perdu, parce qu'il n'existait que dans le Codespace et n'a jamais été envoyé sur GitHub.
